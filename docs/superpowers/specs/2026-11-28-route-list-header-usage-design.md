# 路线列表顶栏与使用次数

## 目标

路线列表在卡片上方增加粘性顶栏（与记录列表月份顶栏结构相似、内容不同），展示：

- 路线总数：`importedRoutes.count`
- 总使用次数：训练结束并保存时，若选中了路线库中的路线，计 1 次

空列表仍只显示「还没有导入的路线」，不显示顶栏。

## 计数（方案 B + 存法 1）

- 时机：训练结束并 `addWorkout` 时。
- 在 `WorkoutRecord` 写入可选字段 `plannedRouteID`。
- 仅当草稿 `routeID` 能命中 `savedRoutes` 中的一条时写入该 id；自由跑、未知 id、以过往训练轨迹为计划时不写。
- 总使用次数 = `workouts` 中 `plannedRouteID` 非空的条数（可复算；路线删除后历史次数仍计入）。

## 顶栏

- 粘性，放在 `ScrollView` 外上方。
- 左对齐两项：`N 条路线`、`M 次使用`。
- 不使用记录页月份标题样式；字号接近月份标题，偏数据展示。
